# AWS S3 Static Website Hosting

## Project Overview

This project demonstrates the deployment of a professional static portfolio
website using Amazon S3 Static Website Hosting.

## Objective

The objective of this project is to host a portfolio website without
provisioning a traditional web server.

## AWS Services Used

- Amazon S3
- S3 Static Website Hosting
- S3 Bucket Policy

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## Features

- Responsive portfolio website
- Professional profile section
- Skills section
- Projects section
- Education section
- Contact section
- AWS S3 hosting
